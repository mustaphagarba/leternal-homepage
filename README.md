# Leternal Inc website

Static React site (React 18 via CDN, htm for templates) for Leternal Systems and Leternal Academy. No build step.

## Edit content
Projects, tracks and events live in the `D` object near the top of the script in `index.html`.

## Run locally
    npx serve .

## Deploy
Import this repo in Vercel. Framework preset: Other. Build command: none. Output directory: `.`

## Before launch
See section 8 of the spec: logo, cleared portfolio items, confirmed fees and dates, photo consent, form backend, analytics.
